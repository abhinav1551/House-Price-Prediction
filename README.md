## House Price Prediction in India 

This project aims to predict house prices in India using machine learning techniques. It utilizes a dataset containing various house features and applies data preprocessing, exploratory data analysis (EDA), and machine learning models to make accurate predictions.

### Machine Learning Models 🤖

For prediction, I implemented multiple models including **Decision Tree**, **Random Forest**, **Linear Regression**, and **XGBoost**. These models were compared to evaluate their performance in finding the relationships between housing features and prices.

### Interactive Shiny Dashboard 📊

To complement the analysis, I developed an interactive web dashboard using **R Shiny**. This dashboard allows users to dynamically explore the dataset and visualize the relationships between key housing attributes and their impact on price.
